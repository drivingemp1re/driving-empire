## 🛠️ Troubleshooting Common Issues

*   **Error: Physics De-Sync Detected**
    *   Description: The vehicle physics thread is updating faster than the game server updates coordinates.
    *   Solution: **Increase the execution delay settings in your config.json file to give the system more buffer time.**
*   **Error: UI Failing to Render**
    *   Description: The engine is unable to compile custom layout tables.
    *   Solution: **Verify that the GUI framework library you are importing is fully compatible with modern standard Luau environments.**
*   **Error: Execution Timeout**
    *   Description: A script containing an infinite loop without exit logic blocked the runtime compiler.
    *   Solution: **Force restart your environment and insert appropriate sleep or wait intervals within the custom loop structures.**
*   **Error: Storage Access Refused**
    *   Description: The editor is unable to read or write setup parameters to your local directory.
    *   Solution: **Ensure your parent folder is excluded from local security checks and run the system with elevated privileges.**
